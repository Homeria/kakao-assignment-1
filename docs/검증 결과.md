# 최종 검증 결과

## 실행 환경

- Frontend: Next.js App Router, React, TypeScript, Tailwind CSS
- Backend: FastAPI, SQLAlchemy, Pydantic, SQLite
- 데이터 저장: FastAPI 서버와 SQLite DB
- 프론트-백엔드 연결: Next.js API Route 프록시

## 명령어 검증

### Frontend

- [x] `npm.cmd run lint`
- [x] `npm.cmd run build`

### Backend

- [x] `.\venv\Scripts\python.exe -m py_compile main.py`

## API 검증

임시 백엔드 포트 `8014`와 임시 프론트 포트 `3020`을 사용해 3000번 개발 서버와 충돌하지 않도록 검증했다.

- [x] `GET /health` 응답 확인
- [x] `POST /api/todos`로 Todo 생성
- [x] `/todos?date=YYYY-MM-DD` 페이지에서 생성된 Todo 렌더링 확인
- [x] `PUT /api/todos/{todoId}`로 Todo 수정
- [x] `GET /api/todos?date=...&filter=completed&search=...`로 필터와 검색 동시 적용 확인
- [x] `DELETE /api/todos/{todoId}`로 Todo 삭제

## 기능 검증

### Todo CRUD

- [x] Todo 생성 페이지가 표시된다.
- [x] 빈 할 일 입력 시 저장되지 않고 안내 메시지가 표시된다.
- [x] 날짜 입력이 `YYYY-MM-DD` 형식으로 표시된다.
- [x] 잘못된 날짜 형식은 프론트에서 제출 전 차단된다.
- [x] Todo 목록이 선택 날짜 기준으로 표시된다.
- [x] Todo 완료 상태를 토글할 수 있다.
- [x] 완료된 Todo는 취소선과 색상으로 구분된다.
- [x] Todo 수정 페이지가 표시된다.
- [x] Todo 제목, 날짜, 완료 상태를 수정할 수 있다.
- [x] Todo를 삭제할 수 있다.
- [x] 존재하지 않는 Todo 수정 페이지 접근 시 not found 화면이 표시된다.

### 날짜 기반 화면

- [x] 선택 날짜가 한국어 형식으로 표시된다.
- [x] 이전 날짜로 이동할 수 있다.
- [x] 다음 날짜로 이동할 수 있다.
- [x] 월요일부터 일요일까지 주간 날짜 카드가 표시된다.
- [x] 이전 주로 이동할 수 있다.
- [x] 다음 주로 이동할 수 있다.
- [x] 날짜 카드를 클릭하면 선택 날짜가 URL과 함께 변경된다.
- [x] 날짜별 Todo 개수가 표시된다.
- [x] Todo가 0개인 날짜는 불필요한 숫자 배지를 표시하지 않는다.

### 필터와 검색

- [x] 전체 필터에서 선택 날짜의 모든 Todo가 표시된다.
- [x] 진행 중 필터에서 미완료 Todo만 표시된다.
- [x] 완료 필터에서 완료 Todo만 표시된다.
- [x] 필터 상태가 `filter` URL 쿼리 파라미터로 관리된다.
- [x] 검색어가 `search` URL 쿼리 파라미터로 관리된다.
- [x] 검색 입력에는 디바운스가 적용된다.
- [x] 필터와 검색을 동시에 적용할 수 있다.
- [x] 필터링과 검색은 FastAPI 서버 조회 조건으로 처리된다.

### 에러와 빈 상태

- [x] Todo가 없을 때 빈 상태 화면이 표시된다.
- [x] 백엔드 서버 연결 실패 시 `fetch failed` 원문 대신 사용자 친화적인 안내 메시지가 표시된다.
- [x] Next.js API Route에서 백엔드 연결 실패를 `503` JSON 응답으로 변환한다.
- [x] 라우트 단위 `loading.tsx`가 준비되어 있다.
- [x] 라우트 단위 `error.tsx`가 준비되어 있다.
- [x] 라우트 단위 `not-found.tsx`가 준비되어 있다.

- [x] URL 쿼리 파라미터 파싱 로직이 별도 유틸로 분리되어 있다.
- [x] 백엔드 로컬 환경 파일과 DB 파일은 Git 추적 대상에서 제외되어 있다.
- [x] 프론트엔드 로컬 환경 파일과 빌드 산출물은 Git 추적 대상에서 제외되어 있다.

- 기능 완성 이후 유지보수성을 높이기 위해 프론트 API 에러 처리와 백엔드 `main.py` 구조를 별도 리팩토링 커밋으로 분리할 수 있다.
