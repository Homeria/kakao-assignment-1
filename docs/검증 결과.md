# 최종 검증 결과

## 실행 환경

- React
- Vite
- Tailwind CSS v4
- JavaScript
- localStorage

## 명령어 검증

- [x] `npm run build`
- [x] `npm run lint`

## 기능 검증

### Todo CRUD

- [x] Todo를 추가할 수 있다.
- [x] 빈 값으로 Todo를 추가하려 하면 안내 메시지가 표시된다.
- [x] Todo 목록이 화면에 표시된다.
- [x] Todo 완료 상태를 토글할 수 있다.
- [x] 완료된 Todo는 취소선과 색상으로 구분된다.
- [x] Todo를 인라인 입력창으로 수정할 수 있다.
- [x] 수정 중 Enter로 저장할 수 있다.
- [x] 수정 중 Escape 또는 취소 버튼으로 취소할 수 있다.
- [x] Todo를 삭제할 수 있다.
- [x] Todo가 없을 때 빈 상태 화면이 표시된다.

### 필터

- [x] 전체 필터에서 모든 Todo가 표시된다.
- [x] 진행 중 필터에서 미완료 Todo만 표시된다.
- [x] 완료 필터에서 완료 Todo만 표시된다.
- [x] 현재 선택된 필터가 시각적으로 구분된다.

### 일간 뷰

- [x] 선택된 날짜가 한국어 형식으로 표시된다.
- [x] 이전 날짜로 이동할 수 있다.
- [x] 다음 날짜로 이동할 수 있다.
- [x] 선택 날짜별 Todo가 분리되어 표시된다.
- [x] Todo 생성 시 현재 선택 날짜에 저장된다.

### 주간 뷰

- [x] 월요일부터 일요일까지 7일 날짜 카드가 표시된다.
- [x] 날짜 카드를 클릭하면 일간 선택 날짜가 변경된다.
- [x] 이전 주로 이동할 수 있다.
- [x] 다음 주로 이동할 수 있다.
- [x] 날짜별 진행 중 Todo 개수가 표시된다.
- [x] 오늘 날짜와 선택 날짜가 시각적으로 구분된다.
- [x] 새로고침 후 선택 날짜와 주간 뷰 상태가 유지된다.

### localStorage

- [x] Todo 데이터가 JSON 형태로 저장된다.
- [x] 새로고침 후 Todo 데이터가 유지된다.
- [x] 새로고침 후 선택 날짜가 유지된다.
- [x] 새로고침 후 주간 기준 날짜가 유지된다.

## 코드 품질 점검

- [x] 컴포넌트가 도메인별 폴더로 정리되어 있다.
- [x] Todo 조회 UI와 수정 UI가 분리되어 있다.
- [x] 주간 날짜 카드 UI가 분리되어 있다.
- [x] Repository는 localStorage 입출력만 담당한다.
- [x] Service는 Todo 도메인 규칙과 데이터 변환만 담당한다.
- [x] Hook은 상태와 저장소 계층을 연결한다.
- [x] 컴포넌트는 localStorage에 직접 접근하지 않는다.
- [x] Vite 샘플 파일과 미사용 asset을 제거했다.
- [x] 브라우저 콘솔에 에러가 없다.

## 추가 구현

- 과제 검증용 디버그 상태 패널을 추가했다.
- 디버그 패널에서 선택 날짜, 오늘 날짜, 주간 범위, 필터 상태, Todo 통계를 확인할 수 있다.
