# 통합 기능 검증 테스트 시나리오 (Integration Test Cases)

이 문서는 TaskFlow 애플리케이션의 동작 신뢰성과 데이터 정밀도를 철저하게 자동/수동 검증하기 위해 작성된 QA 검증 테스트 시나리오 시트입니다.

---

## 1. 개요
- **테스트 목적**: 각 독립 UI 컴포넌트(주간 뷰, 일간 내비게이션, 입력창, 필터 탭, 목록) 및 전역 상태 관리 모듈(Store, Storage) 간의 유기적 상호 작용과 브라우저 저장소 연동 예외 케이스 점검
- **테스트 환경**: 웹 브라우저 (Chrome, Edge, Safari 등 내장 개발자 도구 활용 가능 환경)

---

## 3. 테스트 수행 방법
1. 로컬 환경에서 브라우저를 통해 `index.html`을 실행합니다.
2. 위 표의 **테스트 시나리오 및 절차(Test Steps)**를 QA-01부터 QA-17까지 하나씩 수동으로 수행합니다.
3. 예상한 결과대로 화면 변화가 일어나는지 정밀 비교합니다.
4. 검증이 완료된 항목의 결과란에 `[x] Pass` 형태로 체크를 채워 넣으며 자산화합니다.
