# 작업 계획서 (Work Plan)

이 문서는 ES Modules 및 모듈형 CSS를 활용해 컴포넌트 및 로직 단위로 모듈화하여 개발하는 Vanilla JS Todo 웹 애플리케이션의 작업 계획서입니다. 요구사항 문서 `0. total structure.md`에 명시된 주요 조건을 완벽히 충족하면서도 가독성 및 유지보수성을 극대화한 구조와 **커밋 분할 전략**을 정의합니다.

---

## 1. 프로젝트 개요
- **목적**: HTML, CSS, Vanilla JS만을 사용한 완성도 높은 모듈형 일정 관리(Todo) 웹 애플리케이션 개발
- **핵심 기술 스택**: HTML5, Vanilla CSS (Modular @import), Vanilla Javascript (ES Modules / ES6+)
- **주요 제한 사항**:
  - 라이브러리 및 프레임워크 사용 금지 (외부 빌드 도구나 의존성 패키지 일체 배제)
  - 메인 테마 색상: `#672be0` 사용
  - 직관적이고 구체적인 변수명/함수명 작성 및 동작 원리를 명시하는 상세 주석 작성
  - 완료 후 구현 기능 체크리스트 제출
- **폴더 및 파일 분할 구조**:
  ```
  ├── index.html            # 전체 레이아웃 뼈대
  ├── style.css             # 메인 CSS 엔트리 포인트 (CSS 모듈 취합 및 @import)
  ├── app.js                # 엔트리 포인트 (Store 인스턴스화 및 컴포넌트 초기화)
  ├── css/                  # CSS 모듈 폴더
  │   ├── base.css          # 공통 스타일, CSS 변수 및 리셋
  │   └── components/       # 각 컴포넌트 전용 CSS 스타일
  │       ├── weekly-view.css
  │       ├── date-header.css
  │       ├── todo-input.css
  │       ├── filter-tabs.css
  │       ├── todo-list.css
  │       └── footer.css
  └── js/                   # JS 모듈 폴더
      ├── core/
      │   └── store.js      # 글로벌 상태 관리 및 Pub/Sub 이벤트 버스, 스토리지 연동
      ├── utils/
      │   └── date.js       # 날짜 연산 및 요일 가공 유틸리티 함수
      └── components/       # UI 렌더링 및 개별 컴포넌트 제어 모듈
          ├── DateHeader.js   # 일간 날짜 헤더 및 이전/다음 이동
          ├── WeeklyView.js   # 주간 요일 목록 및 날짜별 Todo 개수 표시
          ├── TodoInput.js    # 할 일 입력폼 및 입력값 누락 에러 메시지
          ├── TodoList.js     # 할 일 CRUD 목록 렌더러 (토글/수정/삭제)
          └── FilterTabs.js   # All / Active / Completed 필터 탭
  ```
- **버전 관리 전략**: 별도의 브랜치 없이 `main` 브랜치 내에서 모듈별 개발 단계에 따라 커밋을 나누어 진행

## 2. 세부 개발 단계 및 커밋 분할 전략

### [1단계] 프로젝트 환경 초기화 & UI 디자인 시스템 구성 (Commit 1)
- **목적**: 완성도 높은 UI 뼈대와 공통 CSS 변수를 이용한 글로벌 스타일 가이드 설계
- **상세 작업**:
  - `index.html` 뼈대 태그 구조 설계 (각 컴포넌트가 마운트될 컨테이너 DOM 요소 구성)
  - `css/base.css` 내 CSS 커스텀 속성(Variables) 정의: 메인 테마 색상 `#672be0`, 명도 대비가 우수한 배경색상군, 모던 쉐도우 및 모서리 곡률(Border-radius) 정의
  - 각 컴포넌트 영역별 CSS 스타일을 `css/components/` 하위 파일로 완벽히 분리하고 `style.css`에서 `@import` 로드 처리
  - Google Fonts(Outfit 또는 Inter)를 적용하고, 부드러운 호버 트랜지션 효과 설정
- **커밋 대상 파일**: `index.html`, `style.css`, `css/` 폴더 하위 CSS 전반
- **커밋 메시지 권장**: `feat: 프로젝트 초기화 및 UI 디자인 시스템 정의`

### [2단계] 상태 관리 Store 개발 및 로컬 스토리지 통합 (Commit 2)
- **목적**: 전역 상태 관리 모듈 구성 및 로컬 스토리지 연동
- **상세 작업**:
  - `js/core/store.js` 파일 생성
  - **Pub/Sub 패턴 구현**: 상태 변경 시 등록된 컴포넌트들이 자동으로 재렌더링되도록 알림을 전송하는 구조 구현 (`subscribe`, `publish`)
  - **State 설계**:
    ```javascript
    state = {
      selectedDate: 'YYYY-MM-DD',
      activeFilter: 'all', // 'all', 'active', 'completed'
      todos: {} // { "YYYY-MM-DD": [ { id, text, completed }, ... ] }
    }
    ```
  - **로컬 스토리지 연동**: 상태가 변경될 때마다 자동 저장(`saveToStorage`) 및 로드(`loadFromStorage`) 메서드 추가
  - `app.js`에서 Store 인스턴스를 초기화하여 전역에서 참조 가능하도록 연결
- **커밋 대상 파일**: `js/core/store.js`, `app.js`
- **커밋 메시지 권장**: `feat: 전역 상태 관리 Store 구축 및 로컬 스토리지 동기화 구현`

### [3단계] Todo 입력 및 CRUD 목록 컴포넌트 개발 (Commit 3)
- **목적**: 할 일 생성, 표시, 완료 토글, 인라인 수정, 삭제 등의 기본 비즈니스 흐름 구현
- **상세 작업**:
  - `js/components/TodoInput.js` 구현:
    - 폼 제출(Submit) 핸들러 바인딩 및 빈 값 입력 시 인라인 안내 메시지 노출 제어
    - 정상 입력 시 `store.addTodo(text)` 호출
  - `js/components/TodoList.js` 구현:
    - `store.subscribe` 등록을 통해 Todo 데이터 변경 시 자동 목록 재렌더링
    - 완료 항목 취소선(line-through) 스타일 바인딩
    - 수정 버튼 클릭 시 인라인 인풋 형태로 노드 전환 및 저장/취소 이벤트 바인딩
    - 완료 및 삭제 버튼 이벤트 핸들러 바인딩
- **커밋 대상 파일**: `js/components/TodoInput.js`, `js/components/TodoList.js`, `app.js`
- **커밋 메시지 권장**: `feat: Todo CRUD 기능 및 입력 유효성 검사 컴포넌트 구현`

### [4단계] 날짜 유틸리티 및 일간 뷰 내비게이션 구현 (Commit 4)
- **목적**: 날짜 연산 처리 및 이전/다음 버튼 클릭에 따른 날짜 전환 흐름 제어
- **상세 작업**:
  - `js/utils/date.js` 구현: 날짜 형식을 변환(예: `2026년 5월 29일 금요일`)하거나 날짜 가산/감산을 처리하는 순수 함수 작성
  - `js/components/DateHeader.js` 구현:
    - `store.subscribe`에 연동되어 현재 `selectedDate` 기반으로 날짜 헤더 정보 출력
    - 이전 날짜 및 다음 날짜 클릭 이벤트를 바인딩해 `store.changeDate(offset)` 호출
- **커밋 대상 파일**: `js/utils/date.js`, `js/components/DateHeader.js`, `app.js`
- **커밋 메시지 권장**: `feat: 날짜 연산 유틸 및 일간 뷰 날짜 내비게이션 컴포넌트 구현`

### [5단계] Todo 상태별 필터링 컴포넌트 구현 (Commit 5)
- **목적**: All / Active / Completed 탭 전환에 따른 할 일 목록의 조건별 필터링 기능 구현
- **상세 작업**:
  - `js/components/FilterTabs.js` 구현:
    - 필터 탭 UI 노출 및 클릭 시 `store.setFilter(filter)` 호출
    - 현재 선택된 필터 탭에 메인 컬러 `#672be0` 하이라이트 효과 적용
  - `TodoList.js`가 필터 상태를 감지하여 렌더링 시 조건에 맞는 Todo 목록만 필터링하여 출력하도록 수정
- **커밋 대상 파일**: `js/components/FilterTabs.js`, `js/components/TodoList.js`, `app.js`
- **커밋 메시지 권장**: `feat: All/Active/Completed 상태 필터링 탭 컴포넌트 구현`

### [6단계] 주간 뷰 컴포넌트 구현 및 날짜별 카운트 연동 (Commit 6)
- **목적**: 주간 요일 정보 표시, 클릭 시 이동 및 각 날짜의 Todo 개수를 직관적으로 안내하는 대시보드 성격의 뷰 구현
- **상세 작업**:
  - `js/components/WeeklyView.js` 구현:
    - 현재 `selectedDate`가 속한 주의 월요일부터 일요일까지 7일간의 날짜를 연산하여 주간 내비게이션 카드 출력
    - 특정 요일 카드 클릭 시 해당 날짜로 `store.setSelectedDate(date)` 호출
    - 스토리지의 요일별 데이터 구조를 순회하여 각 요일별 Todo 개수 연산 및 배지(Badge) 렌더링
  - 디자인 시스템에 맞추어 주간 뷰 카드 배치 및 반응형 스타일 최종 튜닝
- **커밋 대상 파일**: `js/components/WeeklyView.js`, `app.js`
- **커밋 메시지 권장**: `feat: 주간 뷰 요일 패널 및 날짜별 Todo 개수 표시 기능 구현`

### [7단계] 코드 전체 품질 향상 및 상세 설명 주석 보강 (Commit 7)
- **목적**: 최종적으로 변수/함수명 일관성을 확보하고, Vanilla JS 모듈 패턴에 대한 상세 해설 주석 가독성 강화
- **상세 작업**:

  - 주요 Pub/Sub 디자인 패턴 부문과 DOM 조작 및 메모리 누수 방지 처리 영역에 구체적인 주석 삽입
- **커밋 대상 파일**: `js/` 하위 모듈 전반 및 `app.js`
- **커밋 메시지 권장**: `refactor: 변수/함수명 리팩토링 및 시스템 상세 설명 주석 보강`
