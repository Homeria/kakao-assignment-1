## Vanilla JS로 Todo 웹 앱 만들기 

### 조건
- HTML / CSS / Vanilla JS만을 이용.
- Library, Framework 사용 금지.
- Main Color로 #672be0 사용.
- 변수명과 함수명은 역할을 알 수 있도록 명확하게 작성.
- 코드에는 동작 방식을 이해할 수 있도록 주석 작성.
- 기능을 추가하거나 수정할 때는 항상 index.html, style.css, app.js 전체 코드를 파일 별로 나눠서 보여주기.
- 모든 작업을 마친 후에는 어떤 기능을 구현했는지 체크리스트로 답변.


### 작업 순서
#### 1. Todo CRUD(Create, Read, Update, Delete) 구현
- 텍스트 입력창과 추가 버튼으로 Todo를 생성할 수 있어야 함.
- 생성된 Todo는 목록으로 표시되고, 각 항목마다 수정 / 완료 / 삭제 버튼이 있어야 함.
- 입력값이 비어있으면 Todo가 생성되지 않고 안내 메시지를 표시해야 함.
- 완료된 Todo는 텍스트에 취소선이 표시되어야 함.
- Todo 생성 -> 수정 -> 완료 -> 삭제 전체 흐름이 순서대로 잘 동작하는지 확인해야 함.

#### 2. 상태별 필터링 구현
- 전체 / 진행 중/ 완료 필터 탭을 통해 원하는 Todo만 볼 수 있어야 함.
- 현재 선택된 필터 탭은 시각적으로 구분되는 스타일을 적용해야 함.
- 각 탭을 클릭했을 때 해당 상태의 Todo만 표시되는지 확인해야 함.
- 탭 전환 후 새 Todo를 추가했을 때도 필터가 유지되는지 확인해야 함.

#### 3. Todo 일간 뷰 구현하기
- 화면에 오늘 날짜가 표시되고, 이전 / 다음 날짜로 이동할 수 있어야 함.
- 선택된 날짜에 해당하는 Todo만 표시됨.
- Todo를 생성하면 현재 선택된 날짜가 자동으로 저장됨.
- 날짜를 이동했을 때 해당 날짜의 Todo만 표시되는지 확인해야 함.
- 다른 날짜에 Todo를 추가한 뒤 날짜를 이동해도 각각 따로 관리되는지 확인해야 함.

#### 4. Local Storage 연동하기
- Todo의 변경사항은 항상 LocalStorage에 저장돼야 함.
- 새로고침 후에도 기존 데이터가 유지돼야 함.
- 데이터는 JSON 형태로 저장하고 불러와야 함.
    - 예시: JSON.stringify, JSON.parse
- Todo를 추가한 뒤 새로고침해서 데이터가 유지되는지 확인해야 함.
- 브라우저 개발자 도구(F12) -> Application -> Local Storage에서 데이터가 실제로 저장되어 있는지 확인해야 함.

#### 5. Todo 주간 뷰 구현하기
- 이번 주 날짜 목록을 표시하고, 날짜를 선택하면 해당 날짜의 Todo만 볼 수 있어야 함.
- 각 날짜에 Todo가 몇 개 있는지 간략하게 표시해야 함.
