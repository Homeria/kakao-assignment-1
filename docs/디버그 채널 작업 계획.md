# 디버그 채널 작업 계획

## 목적

디버그 채널은 Todo 앱의 실제 기능을 방해하지 않으면서, 개발자와 검토자가 현재 화면 상태와 백엔드 연결 상태를 빠르게 확인할 수 있도록 돕는 보조 기능이다.

3차 과제의 핵심인 Next.js URL 상태 관리, API Route, FastAPI 연동 흐름을 화면에서 확인할 수 있게 하므로 과제 취지와도 잘 맞는다.

## 구현 방향

- `/todos` 화면에 접을 수 있는 디버그 패널을 추가한다.
- 디버그 패널은 기본 Todo 사용 흐름을 가리지 않도록 버튼으로 열고 닫는다.
- 현재 URL 상태와 API query 상태를 표시한다.
- 백엔드 health 상태를 Next.js API Route를 통해 확인한다.
- 디버그 정보는 개발/검증 보조용으로만 사용하고 Todo 데이터 구조 자체는 변경하지 않는다.

## 커밋 단계

### 디버그 커밋 1. 디버그 상태 유틸과 health API 준비

#### 목표

디버그 패널 UI가 사용할 데이터 변환 유틸과 백엔드 상태 확인 API Route를 먼저 준비한다.

#### 작업 범위

- 현재 Todo 검색 상태를 디버그용 데이터로 변환하는 유틸 추가
- 실제 Todo API query를 사람이 읽기 쉬운 형태로 제공
- 백엔드 `/health`를 프록시하는 Next.js API Route 추가
- 클라이언트에서 health API를 호출할 수 있는 함수 준비

#### 제외 범위

- `/todos` 화면 UI 추가
- 디버그 패널 토글 버튼 추가
- 문서 최종 결과 정리

#### 검증

- `npm.cmd run lint`
- `npm.cmd run build`
- `/api/debug/health` Route Handler가 빌드에 포함되는지 확인

### 디버그 커밋 2. 디버그 패널 UI 추가

#### 목표

`/todos` 화면에서 현재 상태와 백엔드 연결 상태를 확인할 수 있는 디버그 패널을 제공한다.

#### 작업 범위

- 디버그 패널 컴포넌트 추가
- 디버그 패널 열기/닫기 버튼 추가
- 선택 날짜, 주 시작일, 필터, 검색어 표시
- 실제 API query 표시
- 마지막 확인 시각 표시
- 백엔드 상태 다시 확인 버튼 연결

#### 제외 범위

- Todo CRUD 동작 변경
- 백엔드 API 구조 변경
- 디버그 정보를 localStorage 등에 저장하는 기능

#### 검증

- `npm.cmd run lint`
- `npm.cmd run build`
- 디버그 패널 열기/닫기 확인
- 백엔드 실행 상태와 중단 상태에서 health 표시 확인

### 디버그 커밋 3. 디버그 채널 문서화

#### 목표

디버그 채널의 목적, 사용 방법, 검증 결과를 문서에 남긴다.

#### 작업 범위

- 프론트엔드 리팩토링 결과 문서 또는 별도 문서에 디버그 채널 설명 추가
- 검증 결과 문서에 디버그 패널 확인 항목 추가
- 과제 보고서에 개발/검증 보조 기능으로 간단히 기록

#### 제외 범위

- 기능 추가
- UI 변경

#### 검증

- 문서에 기능 목적과 검증 항목이 누락 없이 적혀 있는지 확인

## 기대효과

- URL query 기반 화면 상태를 눈으로 확인할 수 있다.
- 백엔드 서버 실행 여부를 프론트엔드 화면에서 바로 확인할 수 있다.
- 과제 검토 시 Next.js API Route와 FastAPI 연결 구조를 더 쉽게 설명할 수 있다.
- 새로고침이나 날짜 이동 후 현재 상태를 오해하는 상황을 줄일 수 있다.

### 화면 사용 방법

1. `/todos` 화면 상단 헤더 오른쪽의 디버그 아이콘 버튼을 클릭한다.
2. 디버그 채널 패널에서 현재 URL 상태와 Todo API 요청 기준을 확인한다.
3. `상태 확인` 버튼을 눌러 백엔드 `/health` 응답을 확인한다.
4. 다시 디버그 아이콘 버튼을 누르면 패널이 닫힌다.

- Todo API query

## 설계 메모

- 디버그 채널은 Todo CRUD 동작을 변경하지 않는다.
- FastAPI 주소는 브라우저에 직접 노출하지 않고 `/api/debug/health`를 통해 확인한다.
- 디버그 패널은 기본적으로 닫힌 상태라 일반 Todo 사용 흐름을 방해하지 않는다.
